# Store logos

Store cards use brand website favicons for the most common chains, with a local Open Today Alicante fallback badge. The fallback keeps cards visually consistent when a brand does not have a mapped logo or the remote logo cannot be loaded.

Mapped chains include Mercadona, Lidl, Aldi, Consum, Charter, Carrefour, Carrefour Express, Repsol, Cepsa/Moeve, bp, Leroy Merlin, MediaMarkt, Supercor, DIA, Hiperber and Dialprix.

The UI is designed so these can be replaced later with local, licensed brand assets without changing the card renderer.
